入口与工作流

前处理 → 手动拓扑，或左侧树中的手动拓扑项。原设计与网格功能保留。独立拓扑包含真实节点、边与可选闭合区域，不是另一个矩形背景尺寸设置。普通实体与手动拓扑在同一项目中独立保留。编译前点击将此拓扑用于网格。

此图展示拓扑草稿与边划分数量，不声称实际单元网格已检查。点击生成/检查真实网格后，在场景查看实际网格。

精确绘制工具

工具操作
直线分别点击起点、终点，不必一直按住鼠标。
连续折线依次点击节点；Esc 或右键结束。
三点圆弧依次点击起点、过点、终点，生成真实圆弧。
圆 / 矩形中心＋半径点生成四段弧；两个对角点生成四条边。
点处打断点在线或弧内部，插入共享节点并拆成两段；圆弧仍保持圆弧。
擦除线段只擦除两个节点之间的那一段，不删除整条折线；破坏闭合后须重新闭合才能生成网格。
选择 / 精确坐标在画布或列表选择节点、边、区域，数值修改 SI 坐标与圆弧过点。
导航 / 恢复滚轮缩放、中键平移、参考网格/节点吸附、F8 正交直线、Ctrl+Z / Ctrl+Y，Delete 删除所选边。

相交曲线必须打断并共享节点；未建立节点的交叉会被拒绝。坐标、标尺、间距与流动 Lref 单位均为米。

分区与独立指派

  1. 先画闭合外边界；在分区端点打断边界，再连接节点建立闭合子区域。
  2. 选择区域，指定流体或排除区，再选择映射四边形、三角形、四边形主导。
  3. 映射区域设置边 1、边 2 单元数与末/首间距比。方向编号按表单下方带符号的逆时针边列表，属于局部分块方向，不一定对应全局 x/y。
  4. 点击应用所选对象。单元数及兼容渐变比通过映射对边与共享接口传播；邻区输入可能随之更新，修改后请检查。
  5. 非结构化区域设置米制目标间距；显式边单元数仍是边界约束。排除区从流体面中扣除嵌套环。
  6. 逐边设置 inlet/outlet/farfield/cylinder 或 interior；内部边必须真实共享。设置明确流动 Lref，不从旧自动实体推断。
R = h_last / h_first > 0
R = 1 : uniform
R > 1 : increasing spacing in a → b direction
0 < R < 1 : decreasing spacing
N cells → N+1 curve nodes
q = R^(1/(N−1)), N > 1
blockMesh simpleGrading uses the total end/start expansion ratio R
Gmsh Progression uses the adjacent-spacing ratio q

N=1 只有一个单元，无实际间距渐变；反转边方向使 R 变为 1/R。可逐条绘制目标网格线，每个合法四边映射小区域可指派单个单元。

实际编译与文件

Manual topology (blockMesh):
manual_topology.json → system/blockMeshDict → blockMesh → constant/polyMesh

Manual topology (Gmsh):
manual_topology.json → geometry.geo_unrolled + geometry.msh
→ gmshToFoam → constant/polyMesh

checkMesh -allGeometry -allTopology
decomposePar → mpirun -np <cores> foamRun -parallel
real processor*/<time>/U,p → VTK viewer / MAT / CSV / GIF

文件 → 生成设计文件 / 所选算例文件查看输入与真实输出。manual_topology_source.py 保留生成器源码。已有显式 blockMeshDict 覆盖须先核对/移除，软件不会静默覆盖。

实现范围

已实现平面手动拓扑、二维单层 empty 算例与真实三维拉伸。blockMesh 要求四边映射区域且无孔；拆边多边形和孔用 Gmsh 三角/四边形主导，主导模式可保留三角/棱柱。Gmsh ≥180° 圆弧须打断。尚不是任意三维实体 CAD/体分块编辑器，也不宣称商业 CFD 认证。原 SSH/求解/后处理功能保留，远程超算实际执行仍未实测。
