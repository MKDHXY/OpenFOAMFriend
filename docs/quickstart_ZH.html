OpenFOAM Friend 0.15

绘制、网格与真实文件访问

完整手册

从这里开始

使用最新桌面快捷方式启动，设置里切换中英文。底部流程选前处理，再用视口上方的设计/网格页签；左侧树选择同一套对象，不会另外生成第二份网格。

已实现平面实体绘制与三维拉伸；新增手动平面节点/曲线/区域拓扑编辑，尚未实现任意三维 CAD 装配。开放直线不会自动变成实体壁面。

1 · 绘制闭合实体

设计 → 多边形实体。逐个点击顶点，Enter 或右键闭合。开放直线/折线仍为辅助线。圆：中心后半径点；矩形/三角形：包围盒两角。仍支持拖绘；Esc 取消，拒绝自交。实体会将不兼容的默认 O-grid 改为 Gmsh；撤销几何时同时恢复原网格方法。

2 · 渐变与加密

单击网格操作 → 加密/间距打开可编辑页。应用保存输入；生成/检查才生成网格。网格 → 绘制加密区域，再点网格间距。可选 uniform 或 x+/x-/y+/y- 渐变。O-grid 使用径向 simpleGrading，矩形区域不加密该拓扑。Gmsh 使用平滑背景尺寸场；分块矩形传播共享边划分以保持共形。

3 · 查看全部生成文件

文件 → 生成设计文件：生成真实 0/U、0/p、湍流场、physicalProperties、momentumTransport、controlDict、fvSchemes、fvSolution、decomposeParDict。结构方法另有 blockMeshDict；Gmsh 有 geometry.msh、geometry.brep 和源码快照。草稿不等于已检查网格；选队列算例可只读查看 constant/polyMesh 与真实时间场。

4 · 手动 blockMesh 代码

选结构方法。生成设计文件 → system/blockMeshDict：编辑顶点、块、圆弧与渐变，保存草稿并应用。实际 blockMesh 使用该覆盖，仍须通过 checkMesh。改用 Gmsh 前须明确移除覆盖。前处理 → 手动拓扑支持节点/曲线/区域绘制；尚不支持任意三维 CAD 拓扑。

5 · 检查、运行、导出

网格 → 生成/检查网格；到场景看实测质量和最坏面。设置物理模型与参考尺度，再运行队列 → 提交设计。监测实际 Co、时间、日志。打开结果后使用场/时间控件，可导出真实 .foam 文件夹、MAT、CSV、GIF。内部积分步长不同于保存帧间隔。

6 · 手绘并指派真实网格区域

前处理 → 手动拓扑。直线两次点击，圆弧为起点/过点/终点，连续折线依次点选。点处打断在线或弧上插入共享节点；擦除只删除两个节点间的一段。闭合面可选为区域。指派映射边单元数与末/首间距比，或 Gmsh 三角/四边形目标尺寸；共享映射边约束传播。点击将此拓扑用于网格，再生成/检查真实网格。坐标与长度单位米。四边映射区域用 blockMesh；拆边多边形或带孔区域用 Gmsh。原几何、求解和导出工具保留。

7 · 单击模型 / PIMPLE / 网格场导出

单击物理连续体、求解器与停止条件、场景与报告的父项或摘要，均打开同一持久属性页。PIMPLE 修改对应 fvSolution，时间/输出对应 controlDict，进程对应 decomposeParDict。应用按钮固定在滚动表单下方；切页和切换语言保留未应用草稿。真实数据加载后才启用结果操作。双击和 Enter 使用相同入口；参数修改与显式代码覆盖冲突时须先核对。

实际执行什么

Structured cylinder O-grid / partitioned box:
system/blockMeshDict → blockMesh → constant/polyMesh

Gmsh triangle/prism, quad-dominant, tetrahedral:
off/mesh.py::build_gmsh → geometry.msh
gmshToFoam geometry.msh → constant/polyMesh
geometry.brep = CAD geometry, not the mesh

checkMesh -allGeometry -allTopology
decomposePar → mpirun -np <cores> foamRun -parallel

Gmsh 三维平面拉伸不代表任意 CAD，四边形主导模式仍可能有三角形/棱柱。两个后端均须通过质量检查后提交求解。

system/decomposeParDict          actual MPI decomposition
system/blockMeshDict             structured mesh input
geometry.msh / geometry.brep      Gmsh mesh / CAD input
constant/polyMesh/*              actual converted/generated mesh
processor*/<time>/*              genuine parallel fields
log.mesh, log.checkMesh, log.solver actual execution evidence

文件 → 生成设计文件按当前项目生成草稿；可编辑的 OpenFOAM 字典保存后成为明确的项目覆盖。文件 → 所选算例文件只读显示当前队列选项；文件 → OpenFOAM 算例目录可查看包括旧版在内的全部 WSL 算例，不必先选队列。文件 → 软件源码只读显示整个软件目录。超过 2 MB 的文本和二进制显示元数据。草稿不是 checkMesh 通过证据，也不是计算完成的算例。
