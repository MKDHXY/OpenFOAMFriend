Real mesh / field / export actions

  1. Select a DONE case in the queue. Click the Mesh/fields/export tree summary or its branch.
  2. Open selected case result, then Show actual mesh or Show pressure. The existing full viewer keeps velocity, vorticity, time, slicing, camera and colour controls.
  3. Export buttons open actual save dialogs. CSV columns and all/current frames are selectable. .foam export copies real case files; a marker alone is not the CFD data. Hover over the source label to see the complete path.
