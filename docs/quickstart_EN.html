OpenFOAM Friend 0.15

Drawing, meshing and actual file access

Full manual

Start here

Launch the latest desktop shortcut. Settings selects English or Chinese. Choose Preprocessing at the bottom stage tabs, then Design or Meshing in the viewport header. The left tree selects the same objects; it does not create a second mesh.

Planar solid drawing and 3D extrusion are implemented. Manual planar node/curve/region topology editing is available; arbitrary 3D CAD assemblies are not implemented. Straight open lines do not become a solid wall.

1 · Draw a closed solid

Design → Polygon solid. Click each vertex; Enter or right click closes it. Open Line/Polyline remain construction references. Circle: centre then radius point. Rectangle/triangle: two opposite bounding-box corners. Drag is still supported. Esc cancels. Self-intersections are rejected. Polygon solids switch incompatible default O-grid to Gmsh; geometry Undo also restores the earlier method.

2 · Grade and refine

Single-click Mesh operations → Refinement/spacing opens the editable page. Apply saves inputs; Generate/check makes the mesh. Meshing → Draw refinement region, then Mesh spacing. Uniform or x+/x-/y+/y- controls local size growth. O-grid uses radial simpleGrading; rectangular regions do not refine that topology. Gmsh uses blended background size fields. Structured partitioned box propagates subdivisions across blocks for conformity.

3 · Inspect all generated files

Files → Generated design files: builds actual 0/U, 0/p, turbulence fields, physicalProperties, momentumTransport, controlDict, fvSchemes, fvSolution and decomposeParDict. Structured methods also generate blockMeshDict. Gmsh generates geometry.msh and geometry.brep plus source snapshot. Draft is not a checked mesh. Select a queue case to inspect constant/polyMesh and real time fields read-only.

4 · Manual blockMesh code

Choose a structured method. Generated design files → system/blockMeshDict: edit vertices, blocks, arcs and grading, then Save draft & apply. This explicit override is used by actual blockMesh. It must still pass checkMesh. Remove the override explicitly before switching to Gmsh. Preprocessing → Manual topology adds node/curve/region drafting; general 3D CAD topology is not implemented.

5 · Check, run and export

Meshing → Generate/check mesh. Inspect actual quality and worst faces in Scenes. Set physical model and reference scales, then Run queue → Submit design. Monitor actual Co, time and logs. Open result → field and time controls; export real .foam folder, MAT, CSV and GIF. Internal integration step differs from saved-frame interval.

6 · Draw and assign actual manual regions

Preprocessing → Manual topology. Line uses two clicks, arc uses start/through/end, Polyline joins successive clicks. Split inserts a shared node into a line or arc; Erase deletes exactly one node-to-node segment. Closed faces are selectable regions. Assign mapped side counts and final/first spacing ratios, or Gmsh triangle/quad target sizes. Shared mapped-edge constraints propagate. Use this topology, then Generate/check actual mesh. Coordinates and lengths are metres. Four-edge mapped regions use blockMesh; split-sided or holed regions use Gmsh. Geometry, solver and export tools remain available.

7 · Click model / PIMPLE / mesh-field-export

Single-click either the branch or its summary under Physics continuum, Solver & stopping criteria, or Scenes & reports. Both open the same persistent property page. PIMPLE changes are applied to fvSolution; time/output to controlDict, ranks to decomposeParDict. Apply is fixed below the scrolling form. Unapplied drafts survive page/language changes. Result actions enable after real data loads. Double-click and Enter follow the same route. Existing code overrides must be reviewed before conflicting parameter changes.

What is actually executed

Structured cylinder O-grid / partitioned box:
system/blockMeshDict → blockMesh → constant/polyMesh

Gmsh triangle/prism, quad-dominant, tetrahedral:
off/mesh.py::build_gmsh → geometry.msh
gmshToFoam geometry.msh → constant/polyMesh
geometry.brep = CAD geometry, not the mesh

checkMesh -allGeometry -allTopology
decomposePar → mpirun -np <cores> foamRun -parallel

Gmsh 3D planar extrusion does not mean fully arbitrary CAD. Quad-dominant mode may retain triangles/prisms. Both backends require quality checks before solver submission.

geometry.msh / geometry.brep      Gmsh mesh / CAD input
constant/polyMesh/*              actual converted/generated mesh
processor*/<time>/*              genuine parallel fields
log.mesh, log.checkMesh, log.solver actual execution evidence

Files → Generated design files creates a draft from the current project; editable recognised OpenFOAM dictionaries apply explicit project overrides when saved. Files → Selected case files shows the queue selection read-only. Files → OpenFOAM run directory exposes all existing WSL cases, including previous versions, without queue selection. Files → Application source exposes the entire application folder read-only. Text over 2 MB and binaries show metadata. A draft is neither checkMesh approval nor a solved case.
