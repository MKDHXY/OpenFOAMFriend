01 · The workbench

OpenFOAM Friend is a working Windows desktop research application by zongxuan and hanwen. It connects to an explicitly configured WSL installation of OpenFOAM Foundation 14. Geometry, meshing, queued MPI solves and result export share a reproducible project and actual case files.

Engineering release 0.16.0. The three short 3D cylinder runs validate the software pipeline, not wake convergence, validated turbulence physics or commercial CFD certification. The current geometry editor constructs planar obstacles and extrudes them into 3D; it is not an arbitrary 3D CAD assembly editor.

02 · Installation and another computer

  1. Keep the timestamped version folder beside runtime. On a new PC install 64-bit Python 3.12, Windows WSL and OpenFOAM Foundation 14 in a Linux distribution. The ZIP contains source and evidence, not a copy of your Linux distribution.
  2. Open PowerShell in the version folder and run the installer below. It creates a local Python environment and downloads the dependencies.
  3. Double-click OpenFOAM Friend.cmd at the package root, or launch.cmd inside the version.
  4. Choose WSL connection & CPU budget. Set the distribution name, actual OpenFOAM bashrc, your Linux run directory, CPU budget and poll interval. Press OK and inspect WSL PROBE in the evidence log. Do not copy the tested host username to a different computer.
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
# Inspect Linux distribution names
wsl --list --verbose
# Example only: replace Ubuntu and the Linux username on another PC
wsl -d Ubuntu -- bash -lc "source /opt/openfoam14/etc/bashrc; command -v foamRun; foamRun -help"

A guided automatic mesh workflow

  1. Draw the geometry, then choose Auto mesh assistant. Confirm 2D/3D and the method: a single circle recommends a cylinder O-grid; general planar obstacles recommend Gmsh triangles/prisms; an empty box can use conformal partitioned blocks.
  2. Choose Quick preview, Balanced or Fine, then adjust actual counts and sizes. O-grid cell count is Nr × Nθ × Nz (Nz=1 for 2D); presets are 5120, 20480 and 81920 in four-layer 3D. The displayed estimate for Gmsh is intentionally not an exact cell count.
  3. For Gmsh, optional near-body and downstream wake rectangles provide smoothly blended size fields. The assistant clips them to the rectangular domain and retains manual regions. The wake direction is x+; ratio controls end/start target size. For O-grid these local controls are disabled: that method supports radial grading, not a Cartesian wake strip.
  4. Set explicit skewness and non-orthogonality limits. Generate and check real preview creates a unique mesh-only WSL case, runs the converter and checkMesh, then opens the real mesh. A failed quality gate stays failed; thresholds are never relaxed automatically. Apply settings only saves design settings without generating a case.

More precise drawing controls

Precise shape creates circle/rectangle/triangle objects with numeric SI dimensions. Double-click a canvas object to edit it. Sketch settings selects ruler units m/cm/mm and snap spacing in metres (0 disables snapping). These settings only change the displayed ruler and snapping, not the physical project units. Select supports a selection box; Ctrl+Z undo, Ctrl+Y redo, Ctrl+D duplicate, Delete removes selected objects, Esc returns to selection. Right-click offers edit/duplicate/delete. Measure provides a live segment preview.

A readable editor for the actual dictionaries

Actual dictionaries opens a grouped system/constant/0 file tree, line-numbered non-wrapping code with syntax colours, search, token-preserving indentation and a parameter reference panel. Format changes whitespace while asserting the exact token sequence is retained. Structure check only validates balanced delimiters and the FoamFile header; it is not a complete OpenFOAM parser. Save current file rechecks that the case is DONE/FAILED/CANCELLED, writes a timestamped backup, then atomically replaces that file. Queued and active cases stay read-only.

Polling now batches live status inside Linux rather than reading hot solver/state files through Windows UNC. Completed-job log summaries are cached. The actual dictionaries and results remain in the WSL case folder. Help → Website support opens spaceaero.space.

The previous global sketch toolbar appeared over every page because it belonged to the main window. This release uses context: Geometry exposes sketch/edit/mesh preparation; Scenes exposes fit/quality/image controls and the real VTK field/time controls; Run Queue exposes refresh, connection and case-code controls. Enable or disable the guide

Settings → Guided workflow shows or hides the optional guide; the choice is saved alongside the language preference. Expert mode is the same application with the guide hidden. The guide is a dock, not a blocking wizard: other workspaces remain accessible. Close its dock or uncheck the menu to return to expert mode. Reset workspace layout restores dock positions without replacing the project.

03 · Dimensioned geometry and control regions

  1. Start with Cylinder preset or open a project. Set domain dimension, rectangular bounds and extrusion depth. All values are SI: metres, seconds, m/s and m²/s. For an O-grid the actual outer boundary is a circle of outer_radius; rectangular xmin/xmax do not define that topology.
  2. Choose Circle, Rectangle or Triangle and drag a bounding box. Select and move objects; double-click their tree entries for exact centre and size. Circle width is diameter; equal width/height is required by the cylinder O-grid. Eraser deletes an object; Undo restores the previous sketch.
  3. Wheel zooms the sketch; Pan drags the view; Fit fits the domain. Pointer coordinates use metres; Sketch settings selects ruler units m/cm/mm and snap spacing (0 disables snapping). Precise shape and numerical dimensions support small geometries. Measure reports distance.
  4. Draw Mesh region rectangles and edit x/y/width/height, size, direction and ratio. A mesh region is a control object, not a solid obstacle. Choose the supported method below before generation.
  5. Save project before submission. A unique safe case name prevents overwriting existing results. Changing the sketch after submitting does not change that queued case snapshot.

04 · Mesh methods and directional grading

MethodCellsControls / scope
Structured cylinder O-gridConformal quadrilateral cross-section / hexahedral volumeExactly one circle; radial, circumferential and spanwise counts; radial simpleGrading. Rectangular control regions are not used by this method.
Structured partitioned boxManual shared block partitions / hexahedraEmpty rectangular flow box; erase all obstacles first. Region edges become shared x/y partition lines. Counts and grading propagate along shared axes for conformal interfaces.
Gmsh triangle / prismAutomatic triangles extruded to prismsCircle/rectangle/triangle obstacles and smooth region size fields. In 2D, one empty layer; in 3D, specified spanwise layers.
Gmsh quadrilateral / prismAutomatic quad-dominant mixed hex/prismRecombination does not guarantee an all-quad mesh. Inspect the actual converted mesh and quality.
Gmsh tetrahedralAutomatic 3D tetrahedraExtruded volume geometry; HXT algorithm and Netgen optimization; no 2D tetrahedra.

Uniform and increasing / decreasing size

For manual blocks, ratio is last-cell width / first-cell width in the selected positive axis; negative directions invert it. Uniform means ratio 1. For N cells and expansion E, adjacent growth g = E^(1/(N−1)); first width is L(g−1)/(g^N−1), or L/N at E=1. This is not a per-cell factor E.

blockMesh: hex (...) (Nr Ntheta Nz) simpleGrading (E 1 1)
Gmsh x+ size target: h(x) = h0 × ratio^((x − x0)/width)
Gmsh x−: use the inverse exponential; y directions are analogous.
Smooth transition: h = h_background + W(x,y) × (h_target − h_background)
W: product of four tanh edge weights; overlapping fields use Min.

Gmsh regions specify target sizes, not exact final element widths. The tanh blend reduces abrupt size transitions; smoothing iterations and curvature resolution complement it. They do not guarantee acceptable skewness: the OpenFOAM gate remains mandatory. For a high-quality cylinder baseline, prefer the structured O-grid and moderate adjacent growth. Six-faced hexahedra are supported; arbitrary 2D hexagonal polygon tilings are not implemented.

Use Generate / check mesh only before an expensive solve. Select the resulting queue row and Open result to view the real mesh. A .foam file is a marker pointing to the complete case directory, not a self-contained mesh file.

05 · Quality, bad faces and singular cells

Every submitted mesh runs checkMesh -allGeometry -allTopology with the project’s explicit skew and non-orthogonality thresholds. The solve is blocked unless its log contains Mesh OK. Default project limits are skewness 0.5 and non-orthogonality 30°. These are chosen gates, not universal accuracy criteria. Quality above a threshold is counted by face, not silently relabelled as cell count.

MetricDefinition / provenance
Non-orthogonalityInternal face angle α=acos((Sf·d)/(|Sf||d|)); d=neighbour centre−owner centre. 0° is orthogonal.
OpenFOAM face skewnessOffset sv=Cpf−d(Sf·Cpf)/(Sf·d), normalized by max(0.2|d|, maximum point projection along sv). Boundary faces use normal projection and factor 0.4. Uses Foundation14 meshCheck formulas; it is not the triangle-angle skewness diagram metric.
Aspect ratio / ARReported directly from checkMesh; it describes cell stretching and is not used as a replacement for skewness or orthogonality.
Singularity indicatorsIndependent signed-volume count/minimum plus OpenFOAM topology, determinant, concavity and geometry checks. Red markers show the worst face location, not every possible mathematical singularity.

Select a case in Run Queue, then click Locate worst skewness / non-orthogonality. The viewer draws the actual faces, colours their calculated metric and places a red marker at the worst face centre. IDs, XYZ coordinates and threshold counts appear in the log and off_quality.json. Calculation uses the actual ASCII polyMesh, including volume-weighted cell centres. Binary imported meshes need conversion to ASCII for this independent audit.

07 · Queue, parallel jobs and restart

Submit snapshots the project. The durable SQLite queue claims CPU reservations transactionally. Jobs can run simultaneously when their summed requested cores fit the budget; four-core jobs under a budget of four run sequentially. A scheduler lock prevents GUI and headless worker from launching the same job twice. Each case records stage files, logs and verified MPI process IDs.

QUEUED → STARTING → MESHING → CHECKING → RUNNING → EXPORTING → DONE
                         quality failure / solver failure → FAILED
RUNNING ↔ PAUSED; lost heartbeat → STALLED; explicit cancellation → CANCELLED
  • Select a row to see actual logs, residuals, max observed Co and checkMesh metrics. ETA extrapolates recent simulated-time progress; it is an estimate and changes with solver speed.
  • Earlier / Later reorders queued jobs. Pause sends STOP only to the verified case MPI launcher and descendants; Continue sends CONT. Pause does not erase or rewrite fields.
  • Cancel supports queued or running/paused solver cases. Meshing/checking/export cannot currently be cancelled from the GUI. A paused job keeps its CPU reservation.
  • Closing the GUI leaves running detached WSL drivers alive and starts a hidden headless scheduler if work is queued. Reboot terminates solvers; pause is not persistent process suspension across a reboot.
  • After reboot reopen the same version. Inspect logs and choose Recover checkpoint for FAILED / STALLED. Recovery requires no live old MPI process, enough CPU budget, and matching complete U,p saved times in every processor. It resumes latestTime without remeshing. Recovery after solver completion but export failure requires manual reconstruction/export.

08 · VTK viewing, animation and PINN exports

Open result loads the genuine reconstructed .foam case with vtkOpenFOAMReader. Select Mesh, p, U or other available cell arrays; U uses vector magnitude colouring. Toggle Edges; choose Full volume or XY/XZ/YZ mid-slice. Wheel zooms, left drag rotates, middle drag pans; Fit resets the camera. Clicking reports a displayed cell ID and XYZ. The slice cutter preserves quadrilateral polygons when present; existing triangular cells remain triangles. Rendering does not alter the OpenFOAM mesh.

  • PNG exports the rendered VTK view. GIF visits the actual saved CFD times; playback uses 150 ms per image and is not physical-time playback. It does not synthesize intermediate CFD frames.
  • CSV: enter comma-separated column names (x,y,z,t,U_x,U_y,U_z,U_mag,p), choose current/all times and positive row stride. Coordinates are cell-centre samples. This is a row-stride selector, not an arbitrary spatial query/filter engine.
  • MAT contains xytuvp (Nrows,6), full xyztuvwp (Nrows,8), actual time_values_s, column names, units and z_planes. Rows are time-major, then cell order. For a 3D PINN use xyztuvwp; xytuvp drops each row’s z and w and is insufficient to define a full 3D learning problem. No implicit nondimensionalization is applied.
from scipy.io import loadmat
a = loadmat("round3.mat")
full = a["xyztuvwp"]  # columns: x,y,z,t,u,v,w,p
time = a["time_values_s"].ravel()
# A 2D model may use xytuvp only after explicitly selecting a z plane.

Large full-field MAT/GIF exports build arrays in memory. For large production runs, use smaller saved-field sets or CSV stride; streaming HDF5/VTU exports are a future extension.

09 · Actual force FFT and Strouhal definition

Postprocess → Force history & single-sided FFT reads genuine OpenFOAM forceCoeffs data and displays Cd/Cl history with the lift amplitude spectrum. There is no Hann window, smoothing, filtering, zero padding or mean removal. The DC bin is retained; the annotated peak is the largest non-DC bin, not automatically a validated shedding fundamental.

Fs = 1 / Δt_sample;  f_Nyquist = Fs / 2
f_k = k Fs / N;  Δf = Fs / N = 1/(N Δt_sample)
Y_k = FFT(Cl)_k;  A_k = |Y_k| / N
Single-sided: double positive-frequency bins, except DC and even-N Nyquist.
St = f_s D / U∞

Adaptive solver timesteps can produce nonuniform force samples. The dialog tests spacing and explicitly reports linear resampling to the median interval before FFT when needed. This is uniform-time resampling, not denoising. Saved U,p frame spacing is separate from force sampling. Nonuniform cases would need a different spectral method if resampling is unacceptable.

Require many stationary shedding cycles, adequate sample rate and a common late-time window before reporting St. A peak spread across neighbouring bins can be finite-record leakage; harmonics occur near integer multiples, while transient and modulation peaks need time-history evidence. Nyquist prevents aliasing only when the sampled signal is appropriately band-limited. These validation records are too short for a defensible shedding St.

0.4 · Construction tools, spacing and initial files

  1. Geometry → Line: drag between two snapped endpoints. Polyline: click vertices; Enter or double-click finishes; Escape cancels. Exact line opens coordinate pairs in metres. Double-click a stored curve to edit its points. Undo/redo, duplicate, move and delete include curves. Orange dashed curves are construction references: they do not cut the fluid domain. Closed arbitrary polygon obstacles remain future work.
  2. Draw a Mesh region, then open Mesh spacing. Choose O-grid radial grading or R1/R2, Uniform / Increasing / Decreasing, direction and coarse/fine ratio. Preview displays the formula and endpoint values. For radial blocks, q=R^(1/(N−1)); h_i=L q^i / Σq^j. R means last-cell / first-cell width, not adjacent-cell ratio. R<1 decreases spacing.
  3. Region Gmsh targets use h(s)=h_start R^s with s clamped to [0,1]. A negative direction measures s from the opposite edge. Blending, background size caps, curvature and competing regions affect the generated size. A size-field request is not proof that each unstructured cell edge is strictly monotone. Structured partitioned boxes propagate shared subdivisions and restart grading per segment. Verify generated quality before solving.
  4. Initial fields / dictionaries opens a local draft at 0/U before submission. Save each edited file, then close to apply differences to the project. Overrides are serialized in the project and written to each new case. Change Flow settings first; raw overrides persist and can supersede those settings. Pressure p is kinematic m²/s². Formatting preserves tokens; a structure check is not OpenFOAM semantic validation. Running cases cannot be edited through the case editor.
  5. Desktop and Start Menu contain a native OpenFOAM Friend icon. The root launcher reads LATEST.txt; old timestamped releases remain available. install.ps1 recreates shortcuts on another Windows PC.

SSH / Slurm setup and submission

Remote execution has not been validated against a real cluster. Local tests verify host-key enforcement, bundle contents and Bash syntax only. Slurm is supported; PBS is not implemented in this release.
  1. Settings → SSH / Slurm supercomputer. Enter a host or existing SSH config alias, optional username/key, remote root, site OpenFOAM environment command, partition/account, MPI ranks and walltime. Use a local key or SSH agent. Do not paste secrets into reports.
  2. First verify the host fingerprint through your institution and establish known_hosts using normal ssh. The GUI uses BatchMode and StrictHostKeyChecking=yes; it will reject unknown or changed keys. Save & test is read-only and checks foamRun/sbatch/squeue.
  3. Choose an inactive real case with 0, system, constant and either polyMesh or blockMeshDict. Preview the generated Slurm script. Upload copies only those three directories and the reviewed script; it does not upload processor fields or old time folders. Remote existing case folders are protected. To rerun, use a new case name/directory. External include dependencies are not bundled automatically.
  4. Confirm that srun or mpirun matches site MPI configuration. Edit the exact script if needed, then press Upload & submit. A successful numeric sbatch ID is recorded; failures remain visible in the log. Scheduler refresh batches squeue/sacct queries and polls at ≥30 s. Hold/release applies to pending jobs. Cancel invokes scancel after confirmation. Running-job suspend/resume, result download and PBS are future work.
  5. The submitted script checks mesh quality, sets the decomposition count, solves, reconstructs and exports actual VTK. This is a clean run using initial fields, not a remote restart service. Site quotas, scheduler queue times and permissions may reject commands. Scheduler elapsed/walltime are not a trustworthy physics completion ETA.

0.5 · Drawing interaction

Lines and rectangles use drag. Circle uses centre and radius: press at the centre, drag to the radius and release. Polyline uses clicks; Enter, double-click or right-click finishes. Backspace / Ctrl+Z removes the last draft vertex. Escape first cancels the draft while retaining the tool; a second Escape selects. Tools remain active for repeated drawing.

F3 toggles endpoint/midpoint/centre/quadrant snaps; F9 toggles grid snap. Object snap uses a 9-pixel aperture independent of zoom. Shift or F8 constrains line directions horizontally/vertically. Alt temporarily disables snapping. The crosshair indicates the acquired point and the live label shows length/angle/diameter/width/height. Middle-button drag pans without changing the drawing tool; wheel zoom follows the pointer. V/H/L/P/C/R/G/M select the corresponding tools when the canvas has focus. Ruler clicks do not create objects.

This is tested interaction functionality, not a formal usability study. Construction curves still do not form arbitrary solid obstacles. Remote Slurm remains untested against a real cluster. The previous strict-shell environment incompatibility is corrected by avoiding nounset during OpenFOAM setup; the local environment now loads successfully.

11 · Industrial references and design choices

The design borrows workflow principles, not proprietary implementations: staged geometry→mesh→solve guidance from Ansys; a shared object tree from SALOME; wall-spacing/orthogonality inspection from Pointwise; persistent view/field/time controls from ParaView. Qt Graphics View supplies native sketch interaction, Gmsh provides OCC operations and size fields, and VTK provides the real result rendering.

Recommended next engineering priorities: constrained sketch dimensions and richer block topology; independent 3D CAD import; boundary-layer/y+ tools; long-window convergence studies; streaming exports; automated installer and physical second-PC tests. These are not presented as existing features.

Isolated dynamicLagrangian compatibility module

The installed Foundation 14 constructor requires dimensionless flm/fmm, but its dimensional transport equations require velocity^4. Both failures were reproduced and retained. The GPL source module renames the runtime model to offDynamicLagrangian and corrects those two constructor dimension arguments; it preserves the original equations and dimension checking. It compiles with wmake into a version-specific user library. Installed /opt/OpenFOAM files are not modified. First use on another WSL/Slurm host requires Foundation 14 development headers, wmake and a C++ compiler. The case/SSH bundle includes source, Make files, COPYING and provenance; compilation errors appear in the case logs. The generated momentumTransport model name is therefore offDynamicLagrangian, while the GUI lists dynamicLagrangian with a compatibility explanation. Real remote Slurm execution remains untested.

0.11 · Recommendations grounded in the current mesh

Setup advice offers two goals: engineering mean/URANS comparison, or resolving 3D wake fluctuations. The recommendation is a transparent starting heuristic, not a universal Reynolds-number threshold for turbulence. For the circular-cylinder screening, Re_D<300 offers laminar; above that engineering comparison offers SST, while a resolved-wake goal offers WALE only with 3D eligibility. These 300/10⁵ bands are application heuristics, not claimed physical transition boundaries. Geometry, inlet turbulence, roughness, wall treatment, uncertainty and benchmark evidence still govern the decision.

Only completed local cases with matching geometry, mesh controls and actual off_project.json metadata can supply mesh evidence. The report recalculates OpenFOAM-style quality, worst faces, cell count and cylinder wall-normal cell-centre distances. Cache reuse requires the SHA-256 of points/faces/owner/neighbour/boundary and matching quality thresholds. A geometry/mesh change invalidates older matching cases. External mesh edits are not geometrically certified merely by metadata; structured cell-count mismatch blocks application.

Measured first-cell distance is geometric, not y+. y+ stays unknown until measured from a solved case. Re alone never infers y+. LES/DES also needs resolved energy, wall/wake/filter scales, suitable span boundaries and statistical convergence; default front/back symmetryPlane is not a periodic LES span. High-Re cylinder drag crisis/transition depends on roughness and inlet turbulence. When a physical sound speed is supplied, Ma=U/a≥0.3 blocks the incompressible recommendation; without it Mach is explicitly unknown.

G = max_cells [ Σ_faces |(1,0,0) · S_f| / (2 V) ]
Co_uniform = Δt · U · G
Δt_start_estimate = Co_limit / (U · G)

G comes from genuine face area vectors and cell volumes. This uniform-inlet geometric estimate excludes acceleration/crossflow and never replaces actual solver maximum Co or time-step convergence. No automatic change to dt, end time or mesh is made. Application is disabled without matching mesh evidence, for invalid/excessive quality, non-finite metrics, high Mach or dictionary overrides.
