Confirmed root cause

The original 0.12 tree rows had no Qt.UserRole action identifiers and no single-click navigation binding. Clicking these rows only selected text. Earlier tests covered the parent mesh branch and backend functions, but missed these exact leaf/group clicks. A real-mouse baseline reproducer confirmed both dead paths.

Baseline evidence

How to use the repaired pages

  1. Click Mesh operations → Generator in the left tree. The app enters Preprocessing → Meshing and raises Generator properties. Double-click and the mesh-toolbar settings button use the same page.
  2. Change backend/resolution/spacing/quality limits. Click Apply generator settings. A green confirmation appears; invalid input displays a rejection and preserves actual project values. Apply does not generate cells.
  3. Click Refinement / spacing. O-grid uses radial uniform/increasing/decreasing h_last/h_first; irrelevant local coordinates are hidden. Drawn rectangle regions are local size inputs for Gmsh or partitioned box, and do not refine an O-grid.
  4. For local refinement: Draw a refinement region, click two corners, then select R1 in the tree. Choose direction and spacing ratio/size, then Apply spacing settings. Empty region lists explain what to do.
  5. Click Generate / check mesh only to execute blockMesh or Gmsh → gmshToFoam and checkMesh. Inspect actual quality; submit the solve separately. Manual dictionary overrides remain authoritative and are explicitly disclosed.

Two engineer rounds — defects, repairs, acceptance

Round 1 repaired the missing routes and passed 12 real-click paths. Screenshot review then found scrolling-away tabs and irrelevant radial coordinate controls. Round 2 fixed those problems, bilingual labels and retention of unapplied inputs; rechecked the 12 paths from all stages in Guided and Expert modes, double clicks, toolbar routes, hidden/floating docks, invalid input, local region edits and both preserved advanced dialogs.

Engineering ledger · Round 1 mouse tests · Round 2 mouse tests · Local-region and legacy-dialog tests
