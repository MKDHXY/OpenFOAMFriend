OpenFOAM Friend 0.17.0 · 离线安装说明

作者：zongxuan & hanwen。Windows x64 软件；欢迎页和安装器均可选择中文 / English。

选择哪个包

包自带 Windows 环境WSL / OpenFOAM
FULL 完整包Python 3.12.10、Qt/PySide6 6.11.2、VTK 9.6.2、Gmsh 4.15.2、NumPy/SciPy 等Microsoft WSL 2.7.14 MSI + 干净 Ubuntu 24.04 镜像：OpenFOAM Foundation 14、MPI 4.1.6、Linux Gmsh 4.12.1
LITE 简易包相同，电脑不用安装 Python只读检查；缺少时显示错误。不会启用 Windows 功能、安装 MSI、导入 Linux 或执行 apt/pip。

对方第一次使用完整包

  1. 把整个 ZIP 复制过去，解压到本地可写目录，不能直接在 ZIP 里面运行。至少预留 10 GB，建议 15 GB 以上。Windows 10 build 19041 或更新版本 / Windows 11，Intel/AMD x64；本包不支持 ARM64。CPU 虚拟化必须在 BIOS/UEFI 启用。
  2. 双击 Setup.cmd，上方选择语言。点击“1 · 准备 Windows / WSL”，接受 UAC 管理员授权。它使用本地 Microsoft MSI，启用所需 Windows 功能，不下载个人发行版。
  3. 若提示重启，保存工作后自行重启。安装器不会强制重启。重启后重新双击同一个 Setup.cmd。
  4. 以普通用户点击“2 · 安装软件与 Linux 镜像”，选择空目录。默认发行版 OpenFoamFriend-14，默认普通用户 off。同名非本软件发行版、非空陌生目录受到保护。可改专用发行版名称。
  5. 安装完成后点“启动”，或使用桌面 / 开始菜单的 OpenFOAM Friend 快捷方式。欢迎页右上角直接切换中文 / English。WSL 配置与软件安装会自动连好；已有配置先备份。

简易包

解压后双击 Start Portable.cmd 可直接运行，不必安装。也可用 Setup.cmd 安装本软件与快捷方式。用 Check Environment.cmd 只读诊断；缺少环境退出码为 2。没有 OpenFOAM 时可设计几何、预览网格和编辑代码，提交求解需要你已有的 OpenFOAM Foundation 14 环境。进入 WSL 配置自动探测 / 手工指定发行版、bashrc、算例目录。

计算与文件位置

完整包 Linux 算例目录 /home/off/OpenFOAM/off14/run；资源管理器可用 \\wsl.localhost\OpenFoamFriend-14\home\off\OpenFOAM\off14\run。修改发行版名称后替换该段。Python 在安装目录的 runtime 中，软件源代码和双语使用手册在版本目录。配置位于 %APPDATA%\OpenFoamFriend。SSH 连接远端还需要你自己的主机名、账号和密钥，不包含任何凭据。

故障处理

  • 启动没反应：用 Start Console.cmd，保留错误；切勿只复制一个启动文件。
  • WSL 0x80370102：检查 BIOS 虚拟化、VirtualMachinePlatform，重启后重试；虚拟机内部运行还需要嵌套虚拟化。
  • 公司策略禁止 WSL / 无管理员权限：完整包无法绕过策略。联系管理员，或用简易包连接已有环境 / SSH 服务器。
  • 安装器长时间工作：进度条和日志持续显示阶段；首次镜像导入可能需数分钟，不要强制关闭导入。
  • 换电脑不要搬旧队列数据库；项目文件可复制，机器 WSL 路径需重新探测。安装包不带任何个人科研算例、账号、SSH 密钥。

验证范围与限制

本次实际验证结果见 安装包验证记录。安装包包含完整软件源代码，不把历史仿真数据作为本次验证。当前主机已启用 WSL，因此“完全未启用 WSL 的陌生电脑 → UAC → BIOS → 重启”的全过程没有物理实机验证，不能承诺所有电脑一次成功。没有外置 ParaView；软件使用自带 VTK 查看与导出，.foam 可另用 ParaView 打开。短时间三维测试验证工作流，不证明圆柱流场物理统计收敛。

其他自带组件与系统边界

另含离线 OpenSSH 客户端（Microsoft 上游 10.0.0.0p2-Preview，版本标识为上游预览版）；不会安装 SSH 服务器或服务。超算需要你自己的账号、密钥、网络与远端 Slurm/OpenFOAM，本次没有真实集群账号，未验证远端端到端提交。Windows 功能启用禁止自动下载修复文件；若操作系统组件存储缺失或损坏，需要管理员用对应 Windows 安装介质修复，安装包不包含 Windows 操作系统。
