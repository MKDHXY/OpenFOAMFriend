Entry and workflow

Preprocessing → Manual topology, or the Manual topology tree item. Design and Meshing remain intact. This independent graph has real nodes, edges and selectable closed regions; it is not another rectangular background-size control. Ordinary solids and manual topology are retained independently in one project. Choose Use this topology before compilation.

The drawing shows the topology draft and boundary subdivision counts, not a claim that the generated cell grid is already checked. Generate/check actual mesh displays the resulting mesh in Scenes.

Crossing curves must be split and share a node. An unconnected crossing is rejected. No hidden automatic connection is inferred. Coordinates, rulers, spacing and flow Lref use metres.

Partition and assign independent regions

  1. Draw a closed outer loop. Split boundary edges at the partition endpoints; connect those nodes to create closed subregions.
  2. Select a region. Set Fluid or Hole; choose Mapped quad, Triangles, or Quad dominant.
  3. For a mapped region set the cell counts and final/first spacing ratios along side 1 and side 2. Side numbering follows the signed CCW edge list shown below the form; these are local block directions, not necessarily global x/y.
  4. Apply selected object. Equal counts and compatible ratios propagate through opposing mapped edges and shared interfaces. Neighbour inputs can change to enforce conformity; inspect them after edits.
  5. For unstructured regions set target size in metres; explicit curve counts remain boundary constraints. Holes exclude nested loops from the fluid surface.
  6. Choose edge patches: inlet/outlet/farfield/cylinder or interior. Interior applies only to genuinely shared curves. Set explicit flow Lref independently of old automatic solids.
R = h_last / h_first > 0
R = 1 : uniform
R > 1 : increasing spacing in a → b direction
0 < R < 1 : decreasing spacing
N cells → N+1 curve nodes
q = R^(1/(N−1)), N > 1
blockMesh simpleGrading uses the total end/start expansion ratio R
Gmsh Progression uses the adjacent-spacing ratio q

For N=1 there is only one cell and no spacing progression. Reversing a curve changes R to 1/R. Drawing every desired grid segment is possible: use single-cell mapped faces where each is a valid four-edge block.

manual_topology.json → system/blockMeshDict → blockMesh → constant/polyMesh

Manual topology (Gmsh):
manual_topology.json → geometry.geo_unrolled + geometry.msh
→ gmshToFoam → constant/polyMesh

checkMesh -allGeometry -allTopology
decomposePar → mpirun -np <cores> foamRun -parallel
real processor*/<time>/U,p → VTK viewer / MAT / CSV / GIF

Files → Generated design files and Selected case files expose these inputs and real outputs. manual_topology_source.py records the compiler source. Existing explicit blockMeshDict overrides must be reviewed/removed before activating the graphical topology; the software will not silently replace them.

Extended evidence

Implemented scope

Planar manual topology, 2D one-layer empty cases, and genuine 3D extrusion are implemented. blockMesh requires four-edge mapped regions without holes. Split-sided polygons and holes use Gmsh triangles or quad-dominant meshes; quad-dominant may retain triangles/prisms. Gmsh circular arcs ≥180° must be split. This is not an arbitrary 3D solid CAD/volume-block editor or a certified commercial CFD product. Original SSH/solver/postprocessing features remain; live remote-cluster execution is still unverified.

The eight 10-second tests in older manuals are retained from version 0.12 and were not rerun in 0.14. See current_release_scope.json for fresh versus historical evidence.
