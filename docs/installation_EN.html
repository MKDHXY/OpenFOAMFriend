FULL on a new computer

  1. Copy the entire ZIP and extract to a writable local folder. Never run inside the ZIP. Reserve at least 10 GB, preferably 15 GB+. Windows 10 build 19041+ / Windows 11, Intel/AMD x64 only. ARM64 is not supported. Enable CPU virtualization in BIOS/UEFI.
  2. Open Setup.cmd. Select the language. Click “1 · Prepare Windows / WSL” and approve administrator UAC. The bundled Microsoft MSI and Windows features are used.
  3. If a restart is requested, save work and restart manually. No automatic reboot. Open the same Setup.cmd afterwards.
  4. As the ordinary user, select an empty installation directory and click “2 · Install complete software + Linux image”. Default dedicated distribution: OpenFoamFriend-14, unprivileged Linux user: off. Existing unrelated distributions and nonempty unmanaged directories are protected. Change the dedicated distribution name if needed.
  5. Click Start, or use the desktop / Start Menu shortcut. The welcome page has a live Chinese / English selector. WSL settings are configured automatically; existing settings are backed up.

LITE

Open Start Portable.cmd after extraction, or use Setup.cmd for app installation and shortcuts. Check Environment.cmd only diagnoses; missing solver environment returns exit code 2. Geometry, mesh design and code editing remain available without OpenFOAM. Solving requires an existing OpenFOAM Foundation 14 environment; use WSL discovery or configure distribution, bashrc and case path.

Files and administration

FULL case directory: /home/off/OpenFOAM/off14/run; Explorer: \\wsl.localhost\OpenFoamFriend-14\home\off\OpenFOAM\off14\run. Substitute the distribution name if changed. The runtime is in runtime, app source/manuals in the version folder, settings in %APPDATA%\OpenFoamFriend. SSH requires your own hostname, credentials and keys; none are bundled.

Troubleshooting

  • No visible startup: use Start Console.cmd and retain the error. Do not copy a launcher alone.
  • WSL 0x80370102: check BIOS virtualization and VirtualMachinePlatform; restart. Virtual machines require nested virtualization.
  • Corporate policy / no admin rights: the package cannot bypass policy; contact your administrator or use LITE with an existing environment / SSH server.
  • Import takes minutes: watch the progress bar and log; do not forcibly close an active import.
  • Move project files, not another computer’s queue database. Rediscover machine paths. No personal research cases, accounts or SSH keys are included.

Validation and limits

See package verification. Source is included. The host already supports WSL; a physical cold Windows machine, BIOS changes, UAC and reboot sequence have not been tested end to end. This is not a claim of universal hardware compatibility. External ParaView is not bundled; the app provides VTK viewing/export, and .foam can be opened in separately installed ParaView. Short 3D runs validate the workflow, not statistically converged cylinder physics.

Additional bundled components and system boundary

An offline OpenSSH client is included (Microsoft upstream 10.0.0.0p2-Preview, explicitly an upstream preview version). No SSH server or service is installed. Cluster credentials, keys, network access and remote Slurm/OpenFOAM are site-specific; no real cluster account was available for end-to-end remote submission testing. Windows feature enablement prohibits automatic repair downloads. A missing/corrupt OS component store requires an administrator and matching Windows installation media; the Windows operating system is not bundled.
