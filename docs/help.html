1. Choose and install a package

PackageChoose when
FULLYour PC needs the Linux CFD environment. Includes a dedicated Ubuntu 24.04 / OpenFOAM 14 image and local WSL installer, plus the Windows GUI runtime.
LITEYou already have a supported WSL/OpenFOAM environment, or want the GUI without system/Linux installation. Missing dependencies are diagnosed only.
  1. Download and extract the whole ZIP into a writable directory. No system Python installation is needed.
  2. Open Setup.cmd. Select English or Chinese. For FULL, prepare Windows/WSL with administrator permission, then restart manually only if requested.
  3. Install the app into an empty directory. The FULL default dedicated distro is OpenFoamFriend-14; existing unrelated distros are protected.
  4. Start from the desktop shortcut, or use Start Portable.cmd after extraction. The welcome page includes language selection.

Windows 10 build 19041+ / Windows 11, Intel/AMD x64. Reserve at least 10 GB, preferably 15 GB+. WSL needs BIOS/UEFI virtualization; company restrictions cannot be bypassed.

2. Follow a complete project workflow

StepWhat to do
Project and connectionCreate/open a project from Welcome. In WSL settings use automatic detection or specify distro, OpenFOAM bashrc and Linux case root. Recheck these on a different PC.
GeometryUse the preprocessing workspace. Set dimensions/domain in SI, choose 2D or 3D, draw two-click lines, arcs or supported solids. Inspect the model and domain before partitioning.
MeshChoose structured O-grid/partitioned box, automatic Gmsh or manual topology. For manual meshes define nodes, connected curves and closed regions; assign subdivisions and uniform/increasing/decreasing grading.
Quality and filesGenerate the mesh, run checkMesh, inspect actual non-orthogonality/skewness and offending locations. Review generated system/constant/0 dictionaries before submission. A geometry preview alone is not a solver mesh.
Physics and queueConfigure U, viscosity/Re, model, PIMPLE, internal timestep, Courant limit, saved-field interval and cores. Inspect generated code; submit and monitor logs/stages. Pause/continue uses the queue checkpoint workflow.
Results and exportLoad real fields, select U/p/vorticity, adjust colour range and playback speed. Export full .foam cases, VTK, CSV/GIF or MAT. For PINN verify columns, dimensions, pressure units and genuine saved times.
SSH / SlurmUse site-provided host/user and an existing key or ssh-agent. Verify the host fingerprint, remote OpenFOAM initialization and scheduler options. Review the batch script before submitting; no remote account is bundled.

3. Troubleshoot using evidence

SymptomNext action
App does not startRun Start Console.cmd from the extracted package, record its error and confirm you extracted the whole ZIP. Do not copy one launcher alone.
WSL 0x80370102 / restart requiredCheck BIOS virtualization and Windows VirtualMachinePlatform. Save your work and restart manually when asked. A virtual machine may need nested virtualization.
OpenFOAM or distro not foundRun Check Environment.cmd. In connection settings detect/select the correct distro and Foundation 14 bashrc. LITE reports missing Linux components without installing them.
Mesh generation or checkMesh failsRead the first fatal mesh error. Check closed regions, connected endpoints, positive cell counts, boundary assignments and grading. Inspect the actual mesh; do not hide a failed quality check.
Solver fails, diverges or stallsCollect the case stage and last log lines, mesh quality, model/BC settings, latest time, Co and actual timestep. Resolve the cause before resuming; a progress estimate is not completion evidence.
Too few export framesCheck genuine field directories and writeInterval. The saved-field interval differs from the internal solver timestep. Sparse fields cannot be turned into genuine dense outputs by interpolation.
SSH authentication / job rejectedTest login and check the site fingerprint, key/agent, account/partition/CPU limits and remote environment with your cluster administrator. Do not post passwords or private keys.

4. Common questions

Do I need Python, Gmsh or ParaView installed?

The packages include the Windows Python/Gmsh/VTK runtime. An external ParaView installation is optional for opening .foam cases. LITE still needs a configured CFD environment for solving.

Does every model/Reynolds number have automatic validation?

No. Model availability and recommendations do not certify a physical setup. Check dimensions, inlet turbulence, wall resolution/y+, grid and timestep sensitivity, boundary placement and statistical convergence for your problem.

Can I switch language?

Yes, in the installer, the welcome page, Settings and this Help page. English and Chinese manuals are provided.

What was actually tested?

Three fresh 3D 5120-cell/four-rank workflows and genuine exports, independent clean WSL imports, Chinese/space paths and interface regressions. Short runs validate the pipeline, not physical convergence. Cold-machine WSL setup and production-cluster submission remain qualification boundaries.
